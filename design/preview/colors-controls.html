颜色与控件：一页看懂的对照稿

左边是现在跑出来的样子（值逐条取自 web/css/tokens.css 与 web/css/app.css）， 右边是建议改成什么。所有对比度都是实测值，不是估计。

核心思路只有一句：橙色只留给"主按钮"，其余强调交给墨色——现在橙色同时用在按钮和 6 个开关上， 主操作反而不显眼了。

橙 = 主操作 墨 = 选中 / 开关 / 危险 亚麻 = 谨慎 玫瑰 = 导航位置
01

主按钮：白字在橙底上读不清

#fffefb 压在 #ff4f00 上实测 3.27:1，而 14px 正文要求 4.5:1。 两种修法都能达标，我推荐第二种：色相不变，只是压深一档。

现在
3.27:1 ✗ #ff4f00 + #fffefb
4.14:1 ✗ #e14600 压深一档仍不够

按钮文字 14px / 600，按 WCAG 属"小号文本"，需要 4.5:1。
同一问题也出现在内存页的「应用」「切换」和设置页的「检查更新」上。

建议
5.24:1 ✓ #c23f00 + #ffffff
6.65:1 ✓ #a83400

--primary-btn: #c23f00 / hover #a83400， 白字保持不变。橙色饱和度几乎看不出差别，但对比度一步到位。

02

开关：六个橙点在跟主按钮抢注意力

内存页一屏有 6 个开关，全开时是 6 块橙色 + 橙色投影 + 橙色光环，主按钮被淹掉。 开关改成墨色轨道，橙色自然回到"唯一转换动作"的位置上；顺带把 46×26 收到 40×22（Windows 惯例尺寸）。

现在
46×26px · 开态 #ff4f00

开态还用 --toggle-thumb-shadow-on 给滑块加橙色投影， 等于同一个动作强调三次。

建议
40×22px · 开态 --ink

勾选态（复选框）本来就用墨色，两者现在终于是同一种"选中"语言。 橙色只出现在"应用 / 开始清理"这类按钮上。

03

按钮三级：写了三级，只用了两级

app.css 的注释自己写着"三级：primary / secondary（墨）/ tertiary"，但 HTML 里 .btn-secondary 一次都没出现——「开始扫描」「一键加速」「清空回收站」「开始 DISM」 全都和「刷新」「取消」长得一样。补上墨底次级，层级立刻回来。

现在

除主按钮外全同款；"清空回收站"这种不可恢复的操作，视觉重量和"刷新"一样。

建议

三级变成：橙=唯一转换动作，墨=带后果的次级， 白描边=导航/取消。破坏性动作再单独一个 --danger-ink，只在确认框里出现。

04

徽章：一屏六个灰药丸，等于没有信息

"安全"徽章 #75716a on #f0f0ef 只有 4.26:1（不达标），而且每行都有， 纯噪音。改成"只在异常时出现"——安全项不给徽章，谨慎/风险才上色。顺带把 14px 收到 12px，行高不再被撑开。

现在
DirectX Shader 缓存 安全
Edge/Chrome 临时文件 安全
浏览器会话恢复 谨慎
缩略图缓存 风险
安全 4.26:1 ✗ 谨慎 6.15:1 ✓
建议
DirectX Shader 缓存 396 KB
Edge/Chrome 临时文件 未发现
浏览器会话恢复 谨慎
缩略图缓存 风险
安全项默认干净，只有需要你注意的行才出颜色
05

表单控件：三套焦点语言，一个原生箭头

全站 :focus-visible 是 2px 墨描边，但输入框/下拉只有 1px 边框变色（几乎看不见）， 开关又是橙色光圈；下拉框还留着 Edge 的原生小三角，和 6px 圆角的自定义框不搭。

现在
原生箭头
1px 边 · 焦点弱
橙色光圈 · 第三套语言
建议
自绘 chevron
2px 墨描边 · 统一
同一套焦点样式

键盘用户在任何控件上都能看到同一个"焦点框"，位置一致、不依赖颜色。

06

绿色在三个地方，意思是三种

--go #2e7d3e 用来给"以管理员重启"上色，但绿色的默认联想是"已完成 / 安全"； 同一份样式里它又当了设置页图标 hover 色和更新成功点。提权是"警示 + 行动"，应该是最重的那个按钮。

现在
当前是普通权限 —— 有两项功能需要管理员

绿色按钮 + 橙色横幅底 + 黑色正文，三种色彩语言在同一行里。

建议
当前是普通权限 —— 有两项功能需要管理员

去掉 --go，用同一个主按钮。整页只剩一种"要做的事"的颜色， 绿色留给"清理成功"这一个语义。
